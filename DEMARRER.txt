SESSION PHOTOS — VERSION 0.1

Le plugin Windows compile et ses tests automatiques passent.

1. Ouvrir https://github.com/machineareves2-source/SessionPhotos/actions/workflows/build.yml
2. Sélectionner une compilation réussie (coche verte).
3. Télécharger l'artefact « SessionPhotos-Windows-VST3 » en bas de la page.
4. Extraire le ZIP et copier le dossier complet « Session Photos.vst3 » dans C:\Program Files\Common Files\VST3\.
5. Dans REAPER, relancer la recherche des plugins et insérer Session Photos.
6. Activer le transfert, scanner le QR code avec le téléphone connecté au même réseau, puis envoyer une photo.
7. Sauvegarder le projet (Ctrl+S).

Pour un premier essai, fermer et rouvrir le projet afin de vérifier que les photos et les notes sont bien conservées.

README.md contient le mode d'emploi complet. VALIDATION.md précise les tests réalisés.
Le navigateur du téléphone sert d'application compagnon : aucun APK ni compte à créer.
